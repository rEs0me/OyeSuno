# Strict Operational Rules

1. **Targeted Bug Fixing Only**: Focus strictly on resolving compilation errors, build issues, and reported bugs. No unprompted rewrites.
2. **No Unrequested Code Changes**: Only modify the exact lines needed to fix a specific error.
3. **No File Removals**: Do not delete or remove any existing files unless explicitly directed.
4. **Preserve Architecture**: Retain all 15 modules, existing domain models, and established patterns.
